# Chrome-Extension (WorkOnPoint)

![Image](logo.jpg)

This is my project that allows users to set a focus topic and recieve alerts when they are off task.

Functionality: Uses a universal sentence encoder and cosine similarity to tell when the user is off task.

Features: Alerts when off-task, gamification using coins + leaderboard, and seeing weekly focus statistics. 

This is the code for the chrome extension. For the code of the server please look here: https://github.com/Pranavmath/REST-Api-Extension
